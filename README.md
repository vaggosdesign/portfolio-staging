# Vaggos Design Portfolio

Personal UX/Product Design portfolio for **Vaggos Angelis**.

The website showcases selected product design work, professional experience and case studies across B2B SaaS, enterprise software and digital products.

## Website

**Live:** https://vaggosdesign.com

**Staging:** To be added once deployed.

## Project structure

This is a static portfolio website built with HTML, CSS and JavaScript.

The main entry point is:

```text
index.html
```

Supporting assets such as images, styles and scripts are stored within the repository.

## Running locally

You can open `index.html` directly in a browser.

For a local development server, you can also use tools such as VS Code Live Server.

## Deployment

The repository is connected to the staging environment.

Changes pushed to the staging branch can be tested before being promoted to the live website.

```text
Development → Staging → Production
```

This repository is used to develop and maintain my personal product design portfolio.
