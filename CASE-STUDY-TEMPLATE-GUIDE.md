# Vaggos case study template

This template preserves the exact Risk Radar case-study design from portfolio v170/v171.

## What is already included

- Full-width coloured hero with project identity and timeframe
- Hero image sizing and responsive behaviour
- Four overlapping overview widgets for Role, Team, Tools and Tags
- Home-table-style pill tags
- Jump-to navigation
- Blue section dividers with white titles and icons
- Centred quote containers with left-aligned quote text
- Responsive image, process and testing layouts
- Scroll-triggered number-count animations, including Impact statistics
- Centred Thank you closing card
- Two related-project widgets
- Dark mode and the portfolio navigation shell

## Reuse checklist

1. Duplicate `index.html`.
2. Search for `data-template-field` to replace the hero and overview content.
3. Replace the project-specific section copy, images and statistics.
4. Keep each section ID unique and update the Jump-to links to match.
5. For animated statistics, retain the existing count-up classes/data attributes and only change the target number and suffix.
6. Replace the two Other projects cards and destinations.
7. Add any new local images to `assets/` and use relative paths such as `assets/your-image.png`.

The current Risk Radar content remains visible as a worked example, while the template markers make the reusable fields easier to locate.
